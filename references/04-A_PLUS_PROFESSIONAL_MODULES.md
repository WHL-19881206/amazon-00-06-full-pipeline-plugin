# Reference｜Skill 04 Professional Capability Modules

## 1A. PROFESSIONAL CAPABILITY ENHANCEMENT｜A+ 转化架构专业增强

### 1A.1 CUSTOMER JOURNEY → MODULE JOURNEY
7 模块不是固定模板，先构建消费者路径：
`Recognize/Position → Need Match → Primary Value → Differentiate → Prove → Resolve Objection / Fit → Use/Selection/Brand Confidence`。

每个模块必须明确它位于哪个 Purchase Stage、解决哪个 Shopper Question、如果删除会损失什么决策信息。

### 1A.2 FEATURE–BENEFIT–PROOF TRANSLATION
对技术/材料/结构型信息建立：
```text
FEATURE
TECHNICAL_OR_PHYSICAL_FACT
SHOPPER_BENEFIT
WHY_IT_MATTERS
PROOF_ASSET
LIMITATION_IF_ANY
MODULE
```

禁止把“Feature → 情绪营销”直接跳过 Proof；也禁止为了显得专业堆砌买家无法理解的规格。

### 1A.3 OBJECTION RESOLUTION ENGINE
Review/Q&A/Search Demand 中的购买疑虑分类：
`SIZE_FIT | COMPATIBILITY | MATERIAL | QUALITY | SETUP | CARE | WHAT_IS_INCLUDED | PERFORMANCE_EXPECTATION | SAFETY | USE_LIMIT | VARIATION_CHOICE | BRAND_TRUST`。

每个高优先级 Objection 必须分配：`Answer | Truth Source | Best Module | Visual Proof | Residual Risk`。

### 1A.4 MODULE DIVERSITY / REDUNDANCY AUDIT
7 模块完成后检查：
- 是否 2+ 模块在回答同一个问题却没有新增证据；
- Listing/九图已经解决的信息，A+ 是否只是换背景复读；
- 是否存在高优先级疑虑完全没回答；
- 是否 Brand Story 占位却没有真实品牌信息；
- Comparison / FAQ / Technical / Lifestyle 是否真的适合该类目，而不是模板化填充。

低价值重复必须重构成新的决策任务，不以“模块已满”作为完成依据。

### 1A.5 COMPARISON / SELECTION GUIDE
比较型模块优先支持：
- 自家产品家族/型号选择；
- Size/Pack/Feature selection；
- 可验证的 generic alternative 比较。

任何竞品点名、价格、排名、销量、评论或“我们更好”的说法都必须经过当前 A+ Policy 与证据审核；不能从竞品页面抄入。

### 1A.6 PREMIUM INTERACTION SELECTION
Premium 可用时，Video / Hotspot / Carousel / Q&A / Enhanced Comparison 等不是“越高级越好”。选择规则：
- Video：动作、安装、过程或使用理解确实更高效；
- Hotspot：多部位/多功能需要定位解释；
- Carousel：多场景、多角度或系列讲述；
- Q&A：高频疑虑需要低摩擦回答；
- Comparison：帮助正确选型或 Cross-sell。

每个交互模块必须说明 `INTERACTION_VALUE`，否则换成更简单模块。

### 1A.7 SAFE PERSUASION FIREWALL
第三方 A+ 方法中常见的 testimonial、FOMO、urgency、social proof、expert endorsement、guarantee 等，**不得默认使用**。只有同时满足：
`Product Truth + Evidence + Current A+ Policy + Marketplace Rule + User Approval/Brand Truth` 才能进入。

A+ 默认使用可验证的：产品事实、真实场景、尺寸适配、材料结构、操作方式、FAQ、品牌真实信息来建立信任。

### 1A.8 A+ TESTING & PERFORMANCE
如果存在 Amazon Experiments/账户可测试能力或用户提供前后数据，建立：
`HYPOTHESIS | MODULE/CREATIVE VARIABLE | PRIMARY_METRIC | GUARDRAIL | TEST_WINDOW | DECISION_RULE`。

不使用“Time on Page/Scroll Depth”等平台未提供给当前账户的数据冒充真实 KPI；只使用用户真实可获得指标。
